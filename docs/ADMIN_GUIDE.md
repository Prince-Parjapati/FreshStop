# Admin guide (daily routine)
1. Open the admin site → **Approvals**. New payments appear within 15 s.
2. Check the UTR against your UPI app. Warnings show for amount mismatch / duplicate UTR.
3. **Approve** (licence issues instantly; user's app unlocks within ~10 s) or **Reject** with a reason. Use the WhatsApp button to message the user.
4. **Users**: search, Block/Unblock, Reset device (lets a user move to a new phone).
5. **Discount codes**, **Announcements**, **Releases** (paste the GitHub Releases APK URL + version code; tick *Mandatory* to force update), **Support** replies, **Settings** (UPI, WhatsApp, price, maintenance mode, offline grace days).
6. **Audit** shows every admin action.
Data privacy: you can see usage counts only, never a customer's business data (it lives on their phone).
